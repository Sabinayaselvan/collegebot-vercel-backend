# CollegeBot Vercel Backend

This is a serverless backend hosted on Vercel to forward chatbot messages to Botpress Cloud Chat REST API.

### How to Deploy 
### manualy

1. Fork this repo
2. Go to https://vercel.com and create a new project from GitHub
3. Set Environment Variables:
   - `BOT_ID` = Your Botpress Bot ID
   - `API_KEY` = Your Botpress API Key
